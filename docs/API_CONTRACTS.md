# 1. API Overview

BioHub provides a RESTful HTTP API to interface between client applications (such as web dashboards or data pipelines) and computational modules.

- **Base URL:** `http://localhost:8000`
- **API V1 Prefix:** `/api/v1`
- **Documentation Endpoints:**
  - Swagger UI: `/docs`
  - ReDoc: `/redoc`

- **HTTP Method:** `GET`
- **Path:** `/health`
- **Authentication:** None

## 2.2 Resistance Prediction (Module 4)

Evaluates antimicrobial resistance prediction for Escherichia coli isolates against Ampicillin using a trained binary Logistic Regression model.

- **HTTP Method:** `POST`
- **Path:** `/api/v1/predictions/resistance`
- **Content-Type:** `application/json`
- **Authentication:** None

### Request Schema

```json
{
  "sample_id": "SAMPLE-001",
  "features": {
    "marR_S3N": 1,
    "tet(B)": 0,
    "tet(A)": 1,
    "soxS_A12S": 0,
    "aac(3)-IId": 1,
    "aph(6)-Id": 0,
    "aph(3'')-Ib": 0,
    "dfrA1": 0
  }
}
```

#### Field Specifications

| Field | Type | Required | Description / Rules |
| :--- | :--- | :--- | :--- |
| `sample_id` | String | Yes | Non-empty sample or experiment identifier. Surrounding whitespace is automatically trimmed. |
| `features` | Object | Yes | Dictionary containing **exactly 8** canonical genomic feature values. |

#### Canonical Genomic Features (Exact Order & Names)

1. `marR_S3N` (Integer: `0` or `1`)
2. `tet(B)` (Integer: `0` or `1`)
3. `tet(A)` (Integer: `0` or `1`)
4. `soxS_A12S` (Integer: `0` or `1`)
5. `aac(3)-IId` (Integer: `0` or `1`)
6. `aph(6)-Id` (Integer: `0` or `1`)
7. `aph(3'')-Ib` (Integer: `0` or `1`)
8. `dfrA1` (Integer: `0` or `1`)

#### Validation Rules

- `sample_id` must not be empty or whitespace-only.
- `features` must contain all 8 canonical features.
- Unknown, extra, or missing features are rejected with HTTP 422.
- Feature values must be strict binary integers (`0` or `1`). Strings (`"1"`), floats (`1.0`), booleans (`true`), or null values are rejected with HTTP 422.

---

### Response Schema (200 OK)

```json
{
  "sample_id": "SAMPLE-001",
  "prediction_label": "Resistant",
  "predicted_class": 1,
  "resistance_probability": 0.8142,
  "susceptibility_probability": 0.1858,
  "features_analyzed": [
    "marR_S3N",
    "tet(B)",
    "tet(A)",
    "soxS_A12S",
    "aac(3)-IId",
    "aph(6)-Id",
    "aph(3'')-Ib",
    "dfrA1"
  ],
  "model_info": {
    "model_name": "Logistic Regression",
    "model_version": "1.0"
  },
  "scientific_disclaimer": "Research Prediction / Resistance Risk Indicator. Not for clinical use."
}
```

#### Response Specifications

| Field | Type | Description |
| :--- | :--- | :--- |
| `sample_id` | String | Echoed sample identifier. |
| `prediction_label` | String | Phenotype label: `"Susceptible"` (class 0) or `"Resistant"` (class 1). |
| `predicted_class` | Integer | Predicted class (`0` or `1`). |
| `resistance_probability` | Float | Calculated probability of resistance $[0.0, 1.0]$. |
| `susceptibility_probability` | Float | Calculated probability of susceptibility $[0.0, 1.0]$. |
| `features_analyzed` | Array[String] | List of the 8 canonical features evaluated. |
| `model_info` | Object | Object with `model_name` and `model_version`. |
| `scientific_disclaimer` | String | Mandated scientific disclaimer string. |

---

### Error Responses

#### 422 Unprocessable Entity (Validation Error)

Returned when `sample_id` is missing/empty, or when `features` has missing/extra keys or non-binary values.

```json
{
  "detail": [
    {
      "loc": ["body", "features"],
      "msg": "Value error, Feature 'marR_S3N' must be an explicit binary integer (0 or 1), got: '1'",
      "type": "value_error"
    }
  ]
}
```

#### 503 Service Unavailable (Model Not Loaded)

Returned when the prediction model artifact cannot be accessed on the server.

```json
{
  "detail": "Prediction model is currently unavailable or not loaded."
}
```

#### 500 Internal Server Error

Returned when an unexpected server-side error occurs during inference.
